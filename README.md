# My Love's Countdown

Create a romantic, elegant birthday surprise website for my girlfriend. Build the FIRST TWO PAGES only, with a strong love theme, smooth animations, and a premium mobile-friendly design.

PAGE 1 — COUNTDOWN

Create a beautiful full-screen birthday countdown page.

Birthday: October 1

Countdown target: October 1, 12:00 AM

The countdown must automatically calculate the remaining time from the visitor's current date and time and continuously update every second.

Display:

"Something Special Is Coming..."

Then:

"For My Love ❤️"

Show a large countdown timer:

Days : Hours : Minutes : Seconds

Design:

- Romantic pink, red, purple and soft pastel aesthetic

- Beautiful glowing heart in the center

- Floating hearts ❤️

- Subtle rose petals 🌹

- Soft glowing particles

- Smooth fade-in animations

- Elegant glassmorphism/card effect

- Romantic but NOT childish

- Responsive for mobile phones

- Use attractive typography and spacing

- Add subtle background music support, but do not autoplay music unless the browser allows it

- Add a small line such as: "Every second brings me closer to celebrating you ❤️"

When the countdown reaches October 1 at exactly 12:00 AM, trigger a beautiful transition:

- Stop the countdown

- Show animated confetti and floating hearts

- Display:

"HAPPY BIRTHDAY, MY LOVE ❤️"

Then show a button:

"Continue ❤️"

Clicking the button should navigate to PAGE 2.

PAGE 2 — PASSWORD

Create a romantic secret-password page that appears after Page 1.

Heading:

"A Little Secret ❤️"

Message:

"Before you continue, enter the date that means the most to me. 💕"

Create a stylish password input with a lock/heart icon.

Placeholder:

"Enter the password"

Button:

"Unlock My Heart ❤️"

PASSWORD:

Use her birthday date as the password, in DDMMYYYY format. Do not hard-code a birth year unless it is provided. Make the password easy to change in the JavaScript configuration.

For example:

October 1 → 01 + her birth month/year

Behavior:

- Correct password → show a beautiful heart-unlocking animation and proceed to Page 3.

- Incorrect password → show:

  "Almost, my love... try again ❤️"

- Do not reveal the correct password on the page.

- Allow pressing Enter to submit the password.

IMPORTANT

- Make both pages part of the same website/project.

- Use clean HTML, CSS and JavaScript.

- Make it fully responsive for Android and iPhone.

- Ensure the countdown works correctly using the visitor's local time.

- Ensure the transition between Page 1 and Page 2 is smooth.

- Keep the design romantic, emotional, elegant and visually impressive.

- Do not create Page 3 yet.

- Keep the code structured so Page 3 can easily be added later.
